## 1. Project Title
**Laundry Wallah / Laundry Mart - Pure HTML Webpage**

## 2. Assignment Objective
To build a complete, semantic HTML webpage for a laundry service business without CSS frameworks or complex modern dashboards, strictly matching the reference layout in `02.png`.

## 3. Technologies Used
- **HTML5** (Pure semantic HTML markup)

## 4. Features Implemented
- **Header Section:** Main `<h1>` welcome banner.
- **About Section:** Friendly introductory paragraph describing the laundry service.
- **Image Section:** Embedded laundry service graphic (`laundry.png`) with proper accessibility `alt` text.
- **Services Section:** Unordered list (`<ul>`) enumerating available laundry services.
- **Price List Section:** Bordered HTML table (`<table>`) listing services and prices.
- **Book Now Section:** Interactive booking form (`<form>`) with required input fields for name, email, phone number, and a submit button.
- **Footer Section:** Semantic `<footer>` containing direct contact information.
